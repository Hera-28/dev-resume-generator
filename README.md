# Dev Markdown Resume & Bio Generator

A lightweight Python utility script designed to interactively generate clean, recruiter-ready Markdown resume files for developer portfolios and GitHub profiles.

## Key Features
- Interactive Command Line Questionnaire: Quickly input your details without manually editing text templates.
- Automated File I/O: Programmatically compiles and writes profile data directly into a formatted markdown file.
- Professional Layout: Structures skills, projects, and contact info cleanly.
